# SitWell

一个面向久坐人群的轻量健康提醒工具，提供久坐计时、起身活动提醒和盆底肌节奏训练。

> 谢谢 Claude 给的灵感。

## 功能

- 标准模式：久坐 30 分钟，活动 5 分钟
- 专注模式：久坐 40 分钟，活动 5 分钟
- 自定义模式：自由调整久坐与活动时间
- 盆底肌训练：以 3 秒收紧、3 秒放松的节奏完成每组 15 次训练
- 页面内弹窗与系统通知提醒（具体效果取决于浏览器权限）

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

然后访问终端显示的本地地址。

## 构建

```bash
npm run build
```

## 说明

SitWell 是独立制作的健康辅助工具，并非 Claude、Anthropic 或其他第三方的官方产品。

本项目内容仅用于一般健康教育与习惯提醒，不能替代医疗诊断或专业治疗。如训练时出现疼痛或明显不适，请停止训练并咨询专业医护人员。
